## 2. THE FALSIFIERS — what would kill this hypothesis, and each is a real measurement
If a case is a LIPF decoy, it MUST show at least one of these. Each is checkable against a file.
 F1. OCCLUSION / PARALLAX FAILURE. A rastered volumetric image is a projection from a point
     source. It does NOT self-occlude: parts of the shape cannot pass in front of other parts of the
     same shape. Real objects show depth-ordered occlusion. => Test: track a single feature across
     the object's disc as it rotates. If internal features never cross in front of one another,
     the shape is a projection, not an object. THIS IS A ONE-FRAME-PER-FRAME TEST.
 F2. NO PARALLAX AGAINST THE BACKGROUND. A projection has a fixed viewpoint. Background stars/
     terrain must not shift relative to the decoy as the aircraft manoeuvres. => Test: background-
     object parallax over a known aircraft manoeuvre.
 F3. MOTION COUPLING. The patent says the decoy "moves with the aircraft, rather than dropping
     away rapidly like a flare." => Test: compute the decoy's track against the parent aircraft's
     track. Coupled = candidate. Independent = not a decoy.
 F4. EMISSION MISMATCH. Specification: emission "from RF to GAMMA RAYS," created by a LASER —
     i.e. it is PLASMA, so it should be optically luminous, and should NOT be a clean IR signature
     of a hot body. => Test: compare the object's IR behaviour against a flare, against a hot
     engine, and against a low-observable airframe. A flare-like bloom with a moving, manoeuvring
     source is the expected signature.
 F5. SPATIAL COHERENCE. Rastering implies a generated, structured, repeating image. => Test:
     inter-frame correlation. Generated patterns are phase-coherent frame to frame; real objects
     are not.
 F6. ABSENCE OF A CORRESPONDING PLATFORM. A decoy requires a carrying aircraft within sensor range.
     => Test: was there a naval or air asset in the frame? Most UAP videos are naval. If no asset is
     present in the scene, F6 excludes LIPF and this becomes a hard falsifier for the case.
 F7. RESPONSE TO JAMMING / COUNTERMEASURES. A countermeasure is built to be defeated. A real
     object is not. => Test: does the object's behaviour respond to active radar illumination?

## 3. THE HONEST BOUND — why this does NOT explain the famous cases
The patent is a MISSILE-COUNTERMEASURE. It is deployed under attack. No UAP case in the public
record has been associated with an attack on the observing platform. Therefore:
 - LIPF DOES NOT EXPLAIN GIMBAL, GOFAST, OR NIMITZ. Hambling concedes the counter-argument: "It is
   unlikely the Pentagon would release videos of their own secret weapon in a bizarre double bluff."
 - LIPF DOES NOT EXPLAIN THE 1950S WAVE, the CONDON CORPUS, or CONDIGN (1997-2000).
 - LIPF *CAN* EXPLAINE: swarms of orbs near a naval asset; objects with plausible-if-hypothetical
   kinematics near a ship; volumetric ghost aircraft seen at a distance.
 >>> THE RIGHT SCOPE IS NARROW AND THAT IS THE POINT. A bounded hypothesis that nobody has tested is
 >>> worse than no hypothesis, because it means the resolution list was never complete.

## 4. THE QUESTIONS NOBODY HAS ASKED AARO
Written to be sent as a single FOIA/oversight request. Each is answerable from files AARO already
holds. None requires a new investigation.
 Q1. Of the 205 unresolved cases in the FY2025 annual report, how many occurred within sensor range
     of a US or allied naval vessel or a US strike platform?
 Q2. For those, has the raw underlying sensor data (the file the report was derived from) been
     examined for (a) the F1 occlusion test, (b) the F2 background-parallax test, (c) the F3
     motion-coupling test?
 Q3. Has any case been evaluated against the LIPF patent (11,359,892 B2) or against countermeasure
     literature generally?
 Q4. Does AARO hold a copy of the patent, and is it in the reference library of whatever
     classification reference library supports unresolved-case adjudication?
 Q5. In how many of the 205 cases was the raw source data successfully traced back to the
     originating agency? (AARO staff have stated this is not always possible. A case whose raw data
     cannot be retrieved cannot be tested against ANY hypothesis, including a mundane one. This is
     the actual limiting factor on the entire residual, and it is a records-management problem,
     not a physics problem.)
 Q6. For the Navy 2022 Middle East incident (objects "1-2 metres," 80-180 mph): was an MQ-9 or
     other platform in frame, and has the F1-F5 tests been run on that file?

## 5. THE POINT OF DOING THIS
Not to prove the Navy generated UFOs. It certainly did not generate the historical UAP record.
The point is narrower and it is the same point as Project Condign's own recommendation: the
electromagnetic effects and apparent objects associated with the phenomenon are the kind of thing
that is MILITARY-RELEVANT and gets studied, and if a decoy capability exists then the adjudication
list is incomplete until it is checked. AARO resolved 238 cases as satellite flaring in one report.
It is entirely possible that a *second* category of self-generated phenomenon is sitting in the
unresolved bucket unchecked. Nobody has asked. That is the finding.
